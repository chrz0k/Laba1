**1.2. Сумма знаков.**

Дана сигнатура метода: `public int sumLastNums (int x);`

Необходимо реализовать метод таким образом, чтобы он возвращал результат сложения двух последних знаков числа, предполагая, что знаков в числе не менее двух.

Пример:

```
x = 4568
результат: 14
```

### Алгоритм решения

1. Пользователь вводит целое число с клавиатуры. Ввод проверяется: допускаются только целые числа не менее 10 (так как в числе должно быть минимум два знака). При некорректном вводе программа выводит сообщение об ошибке и просит повторить ввод.
2. Последняя цифра числа получается как остаток от деления на 10: `x % 10`.
3. Предпоследняя цифра получается так: сначала целочисленным делением на 10 отбрасывается последняя цифра (`x / 10`), затем от результата берется остаток от деления на 10: `(x / 10) % 10`.
4. Метод возвращает сумму этих двух цифр.

Реализация метода:

```csharp
public int SumLastNums(int x)
{
    int result = x % 10 + (x / 10) % 10;
    return result;
}
```

Пример 1:

```
a = 3 b = 6
результат: true
```

Пример 2:

```
a = 2 b = 15
результат: false
```

### Алгоритм решения

1. Пользователь вводит два целых числа с клавиатуры. При некорректном вводе программа просит повторить ввод.
2. Если хотя бы одно из чисел равно нулю, метод возвращает `false`, так как делить на ноль нельзя.
3. Иначе проверяется, делится ли первое число на второе без остатка (`a % b == 0`) или второе на первое (`b % a == 0`). Если выполняется хотя бы одно условие, метод возвращает `true`, иначе `false`.

Реализация метода:

```csharp
public bool IsDivisor(int a, int b)
{
    if (a == 0 || b == 0)
    {
        return false;
    }
    if ((a % b) == 0 || (b % a) == 0)
    {
        return true;
    }
    else
    {
        return false;
    }
}
```

- лет

Слово "год" добавляется, если число x заканчивается на 1, кроме числа 11.
Слово "года" добавляется, если число x заканчивается на 2, 3 или 4, кроме чисел 12, 13, 14.
Слово "лет" добавляется во всех остальных случаях.

Пример 1:

```
x = 5
результат: "5 лет"
```

Пример 2:

```
x = 31
результат: "31 год"
```

Пример 3:

```
x = 44
результат: "44 года"
```

### Алгоритм решения

1. Пользователь вводит возраст. Ввод проверяется: допускаются только неотрицательные целые числа.
2. Из числа выделяются последняя цифра (`x % 10`) и две последние цифры (`x % 100`).
3. Если две последние цифры лежат в диапазоне от 11 до 14, возвращается строка со словом «лет». Это исключение работает и для чисел 111, 112, 211 и т.д.
4. Иначе, если последняя цифра равна 1, возвращается слово «год».
5. Иначе, если последняя цифра равна 2, 3 или 4, возвращается слово «года».
6. Во всех остальных случаях возвращается слово «лет».

Реализация метода:

```csharp
public string Age(int x)
{
    int lastTwo = x % 100;
    int last = x % 10;

    if (lastTwo >= 11 && lastTwo <= 14)
    {
        return $"{x} лет";
    }
    if (last == 1)
    {
        return $"{x} год";
    }
    if (last >= 2 && last <= 4)
    {
        return $"{x} года";
    }
    return $"{x} лет";
}
```

2. Оператор `switch` определяет по названию дня его порядковый номер в массиве дней недели (понедельник — 0, воскресенье — 6).

{
    string[] days = { "понедельник", "вторник", "среда", "четверг", "пятница", "суббота", "воскресенье" };
    int start;

    switch (day?.Trim().ToLower())
    {
        case "понедельник":
            start = 0;
            break;
        case "вторник":
            start = 1;
            break;
        case "среда":
            start = 2;
            break;
        case "четверг":
            start = 3;
            break;
        case "пятница":
            start = 4;
            break;
        case "суббота":
            start = 5;
            break;
        case "воскресенье":
            start = 6;
            break;
        default:
            Console.WriteLine("Это не день недели.");
            return;
    }

    for (int i = start; i < days.Length; i++)
    {
        Console.WriteLine(days[i]);
    }
}

        {
            result += " ";
        }
    }
    return result;
}

Необходимо реализовать метод таким образом, чтобы он возвращал true, если все знаки числа одинаковы, и false в ином случае.

Пример 1:

```
x = 1111
результат: true
```

Пример 2:

```
x = 1211
результат: false
```

### Алгоритм решения

1. Пользователь вводит неотрицательное целое число. Ввод проверяется.
2. Пока число больше нуля, выполняется цикл.
3. Если число состоит из одной цифры (`x % 10 == x`), цикл прерывается: все пары цифр уже сравнены.
4. Последняя цифра (`x % 10`) сравнивается с предпоследней (`(x / 10) % 10`). Если они различаются, метод сразу возвращает `false`.
5. Последняя цифра отбрасывается (`x /= 10`), и цикл повторяется.
6. Если цикл завершился без возврата `false`, метод возвращает `true`.

Реализация метода:

```csharp
public bool EqualNum(int x)
{
    while (x > 0)
    {
        if (x % 10 == x)
        {
            break;
        }
        if (x % 10 != (x / 10) % 10)
        {
            return false;
        }
        x /= 10;
    }
    return true;
}
```

public int FindLast(int[] arr, int x)

    {
        if (arr[i] == x)
        {
            findX = i;
        }
    }
    if (findX == arr.Length + 1)
    {
        findX = -1;
    }
    return findX;
}

3. Затем элементы вспомогательного массива копируются обратно в исходный массив. Так как массив передается по ссылке, изменения видны вызывающему коду, поэтому метод ничего не возвращает.
4. Измененный массив выводится на экран.

Реализация метода:

```csharp
public void Reverse(int[] array)
{
    int[] newArray = new int[array.Length];
    int j = 0;
    for (int i = array.Length - 1; i >= 0; i--)
    {
        newArray[j] = array[i];
        j++;
    }

    for (int i = 0; i < array.Length; i++)
    {
        array[i] = newArray[i];
    }
}
```

**4.10. Удалить негатив.**

Дана сигнатура метода: `public int[] deleteNegative (int[] arr);`

Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, в котором записаны все элементы массива arr, кроме отрицательных.

Пример:

```
arr = [1,2,-3,4,-2,2,-5]
результат: [1,2,4,2]
```

### Алгоритм решения

1. Массив задан в программе заранее и выводится на экран.
2. Первым проходом по массиву подсчитывается количество отрицательных элементов `countNeg`.
3. Создается новый массив длиной `arr.Length - countNeg`.
4. Вторым проходом неотрицательные элементы копируются в новый массив. Индекс в новом массиве равен `i - countNeg`, где `countNeg` теперь считает уже встреченные отрицательные элементы и сдвигает позицию записи влево.
5. Метод возвращает новый массив, он выводится на экран.

Реализация метода:

```csharp
public int[] DeleteNegative(int[] arr)
{
    int countNeg = 0;
    for (int i = 0; i < arr.Length; i++)
    {
        if (arr[i] < 0)
        {
            countNeg++;
        }
    }

    int[] newArr = new int[arr.Length - countNeg];

    countNeg = 0;
    for (int i = 0; i < arr.Length; i++)
    {
        if (arr[i] >= 0)
        {
            newArr[i - countNeg] = arr[i];
        }
        else
        {
            countNeg++;
        }
    }

    return newArr;
}
```
